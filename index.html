About

會寫程式的人很多，
聽得懂現場在講什麼的比較少。

我是何維治，資訊管理碩士， 目前在製造執行系統（MES）領域已有約 3 年的開發實務經驗。

在邁森科技，我負責產品、訂單、工單、報工、委外等核心模組， 從需求訪談、流程分析、系統設計到程式開發全程參與。 MES 最難的其實不是技術，而是「每一家工廠的做法都不一樣」—— 同樣叫做報工，A 廠是機台自動回傳、B 廠是組長下班前補登。 我在多家客戶的導入與客製過程中，累積了跨廠域的流程比較經驗， 知道哪些是可以抽象成共用邏輯的、哪些必須做成設定。

除了製造流程，我另外具備淨零碳盤查的產業知識 （iPAS 淨零碳規劃管理師），大學專題就是獨立開發一套碳盤查平台。 碩士研究則讓我補上了另一塊能力：用問卷設計與 PLS-SEM 統計分析， 把「使用者為什麼不用這個功能」變成可以驗證的假設，而不是憑感覺猜。

我期望往系統分析與設計方向深化， 成為那種能同時聽懂產業流程、也做得出來的開發者。

碳盤查平台 CARBON INVENTORY PLATFORM

大學專題 · 獨立完成
指導教授：謝佳宏
  • ASP.NET Core MVC (.NET 8)
  • Entity Framework Core
  • MSSQL
  • IIS
  • Azure

Problem 問題

台灣多數企業做溫室氣體盤查仍然靠 Excel 手動填報，檔案版本散亂、係數不一致、計算容易出錯，年度盤查一到就是人工地獄。

Solution 做法

從需求分析、資料庫結構設計到前後端開發全部獨立完成，把排放源、係數與盤查資料結構化收進系統，並實作報表匯出與帳號權限管理。

Result 成果

以系統取代 Excel 流程，讓企業能更快速、準確地計算碳排放量；並實際完成 IIS 與 Microsoft Azure 的部署，驗證整套上線流程。

製造執行系統（MES）核心模組 MANUFACTURING EXECUTION SYSTEM

商業產品 · 邁森科技
2023/07 – 2026/08
  • ASP.NET Core MVC
  • Entity Framework Core
  • Dapper
  • MSSQL
  • jQuery

Problem 問題

製造現場的產品、訂單、工單、報工與委外流程分散在紙本與各自的 Excel，進度看不清楚、資料對不起來，且每家工廠的做法都不相同。

Solution 做法

負責上述五大核心模組的完整開發鏈：需求訪談 → 流程分析 → 系統設計 → 程式實作。資料庫結構自行規劃，並針對大量查詢做效能優化，同時實作 Excel／PDF 報表匯出。

Result 成果

系統實際導入多家製造業客戶並依各廠流程差異客製；在反覆導入的過程中，逐步分辨出哪些邏輯該共用、哪些該做成可設定的參數。
